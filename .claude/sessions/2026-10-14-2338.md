## Design decisions
- **Resume preview is desktop-only.** Chose an iframe overlay on desktop and a direct link on mobile, over rendering the PDF to images. Mobile browsers don't render PDFs in iframes, and images would go stale whenever the PDF changes.
- **Resume preview is a progressive-enhancement link.** `ResumeLink` stays a real `<a href>` and only intercepts plain left-clicks. Chose that over a button, so new-tab and download keep working.
- **OG image extension.** Kept the generated extensionless `/opengraph-image` and fixed its type in `_headers`, over committing a static PNG, so the card regenerates when the profile changes.
- **Favicon.** Rendered once with `ImageResponse` and committed as static PNGs, over a live `app/icon.tsx`. A static file gets a proper `.png` URL and content type.
- **Lazy overlays.** The overlays load on first use with no idle prefetch: an idle prefetch would still count as unused JS. The first-open delay is negligible.
- **Skip link placement.** Placed inside `Header`, not as a `body > a`, so the existing `INERT_TARGETS` selectors cover it under modals.
- **Analytics.** Cloudflare Web Analytics requires a manual token on workers.dev; it can't be auto-injected because there's no proxied zone. It's wired to stay off until the token is set.

## Gotchas / tribal knowledge
- **CDP testing needs a foreground window.** Call `Page.bringToFront`; a background Chrome window throttles rAF, and GSAP `delayedCall`s and close tweens then never finish. That caused a false failure cascade this session.
- **CDP screenshot clips use page coordinates.** Add `scrollY` to `getBoundingClientRect().y`, or the capture comes out blank.
- **Metadata routes need `export const dynamic = "force-static"`** under `output: "export"` (`opengraph-image`, `sitemap`, `robots`).
- **Cloudflare Workers static assets honour `public/_headers`.** `wrangler dev` applies it too.
- **The resume preview iframe swallows Esc** while it has focus, because keydown doesn't bubble out of the PDF viewer. The close button is focused on open.
