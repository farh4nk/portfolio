## Gotchas / tribal knowledge
- **HMR leaves scroll animations stale in dev.** After a component with `data-reveal` hot-reloads, its new elements stay at opacity 0, because PageMotion's ScrollTrigger batch still holds the old nodes. Farhan saw "About is gone" because of this. Fix: a hard reload (⌘⇧R). This doesn't happen in production.
- **Browser verification:** headless `--screenshot` with `--virtual-time-budget` throttles rAF, so GSAP looks frozen. Use the CDP scripts instead: drive real Chrome over `--remote-debugging-port`. A helper lives in the session scratchpad (`cdplib.mjs`); recreate it if it's gone. Set `sessionStorage.booted=1`, then reload, to skip the boot intro in tests. `Emulation.setDeviceMetricsOverride` gives a true 390px width.
- **Lenis vs. native scrolling:** with Lenis active, native `scrollIntoView` gets overridden, while `window.scrollTo` works. In app code, use `lib/scroll.ts` `scrollToElement`, which goes through Lenis.
- **Pin ordering:** the pinned stack scene calls `ScrollTrigger.sort()` and `refresh()` after creating its pin. Triggers created earlier that sit below it, such as the Header's section triggers, would otherwise be mis-measured.
- **The data-attribute selector `[data-node]` is shared** by the timeline nodes and the stack-schematic nodes. Scope queries with `#experience [data-node]`.
- **Images:** filenames must match `content/*.ts` exactly, including the extension. Brain Invaders is `.jpg`. Cards crop with `object-top` unless `imageFocus: "center"` is set.
- **Devpost:** fetch it via `curl https://r.jina.ai/<url>`. Add `-H "X-Return-Format: html"` for the prize, team, built-with tags and links.
