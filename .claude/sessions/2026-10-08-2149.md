## Design decisions
- **Look:** "Blueprint Terminal," a mix of blueprint lab and dark terminal that Farhan chose. Considered and rejected: warm paper/terracotta (too close to the inspiration site), pure terminal, and Swiss minimal.
- **Format:** single long page. He picked it over home plus case-study pages, so project detail lives in full-screen case-file overlays (GSAP Flip, `#work/<slug>` hash).
- **Hero:** live system schematic. Chosen over a cursor-tracking robot face, a perception overlay on the portrait, and a plain typewriter hero. The perception overlay moved to the About portrait instead.
- **Motion extras chosen:** terminal boot intro, terminal easter egg, Lenis smooth scroll with pinned scenes. **Declined: custom cursor and magnetic buttons.**
- **Projects:** only Quenova, MIRA ★ and Brain Invaders ★ get full case files. reciPal, LUNA and NutriScope stay compact inside the 5-node hackathon strip, because he wants the winners emphasized.
- **Stack:** Next.js static export on Cloudflare Workers. Chosen over Astro because he already knows Next.js and his Quenova setup runs on Workers.
- **Removed `cacheComponents` and `partialPrefetching`:** the scaffold defaulted to them, but Cache Components needs a Node runtime, which a static export doesn't have.
- **Domain:** `workers.dev` for now, no custom domain. No phone number on the site. The medical ed role stays generic.

## Gotchas / tribal knowledge
- **Next 16.4 is newer than training data.** `AGENTS.md` says to read `node_modules/next/dist/docs/` before using new APIs.
- **npm 11 blocks install scripts by default.** esbuild, workerd and unrs-resolver were approved via `npm install-scripts approve`.
- **Stray `~/Code/package-lock.json`:** it confused Turbopack's root detection, so `turbopack.root: __dirname` is pinned in `next.config.ts`.
- **Tailwind is wired through the `@tailwindcss/turbopack` loader** in `next.config.ts`, not PostCSS.
- **The `!` bash prefix doesn't work in the VS Code extension.** Run interactive commands like `wrangler login` from the background and have him approve in the browser.
- **Devpost blocks direct fetches** with a Cloudflare challenge. `curl https://r.jina.ai/<url>` works (add `-H "X-Return-Format: html"` for the full page).
- **Loom transcripts failed.** The video is downloadable via `POST https://www.loom.com/api/campaigns/sessions/<id>/transcoded-url`. Extract frames with the Swift AVFoundation script (`ffmpeg` isn't installed).
- **Copy accuracy rule** (also in memory): only state what the code, Devpost or demos confirm.
